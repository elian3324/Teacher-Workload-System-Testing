## 业务流程与字段

- 首页：学年选择、待处理/差异卡片、SIS 同步状态、预算与实际图表、学科部年度平均和合计表、列筛选和 Excel 导出。快捷入口指向待办或结算页面。
- 开课：学年/学期、课程级别、环节、Mode、频率、语言与关键词筛选；列表包含两位教师及授课权重、LEC/TUT、Size/Quota、参与计算等；编辑、复制、版本、导入与历史记录；计划版支持按教师和课程明细；减免按行政/Offer/科研维护；结转显示相对有效标准的正负差额。
- 审批跟踪：学年、学期、状态、课程数、提交人和当前节点；展示主任初审、学院行政复审、主管领导终审的流程。待办另有学院行政主管阶段的标签。
- 结算：批次及预估/实际模式；co-list、SIS 数据与课时导入、五步引擎、计划实际偏差、教师汇总/课程明细、透视与四类报告；支持计算详情与人工调整表单。
- 达标：计划/预估/实际三版、学年/学期/学科部/层次、合同类型/减免/判定筛选；Hours、Courses、Credits、studentNo；减免详情分合同标准、扣减和有效标准。
- 查询：个人信息及课程、管理教师清单、Review 日期段、教师内嵌课程详情与学部汇总。
- 配置：学年状态/生效区间/变更记录及默认复制；学期代码/类型/当前标志；合同标准与容差；规则条件、代码、值和状态；试算工具；特殊课程标志；教师身份、合同、联系方式与登录账号。
- 系统：用户部门树/筛选/导入/更多操作；角色菜单与数据权限、用户分配；菜单树/缓存/图标/路由；部门树；岗位；字典与英文标签/键值/颜色/CSS。

## 当前观测与限制

1. 首页曾显示待办 3 项，而待办任务页面当时为 0；尚需确认角色/状态/学年口径，未将两者强行设置为相等。
2. 原始会话开课学期下拉仅显示全年，未选有效具体学期时新增课程没有打开表单。独立测试会话默认 Term 1，状态为已提交待审批、审批中只读，版本和新导入历史数据入口不可达。新增/复制/提交应先准备可编辑学期。
3. 岗位与特殊审批列表当时为空；个人查询在管理员账号下无教师绑定数据。空态可检查，行内流程需补充测试数据。
4. 分钟规则名称写着 ≥30/≥10，但实际匹配条件为 ≥20 且 <50 / ≥50 / <10；10–19 分钟存在配置覆盖空档，业务应确认。自动边界用例使用实际条件验证 0、9、20、49、50、59。
5. SCH 当前明确跳过，评分权重说明中 P/U 的文字与规则值也有不同。业务预期须单独确认，不能以 UI 存在即推断所有业务规则正确。
6. 全年跨学年结转页面说明读取会写入自动结转账本；调研与标签测试未主动点击刷新/保存。
7. 未切换到其他角色登录；页面中不存在的数据详情无法凭空检查。权限树中出现的基础设施/报表等菜单不属于当前应用侧栏可进入页面，未猜测隐藏 URL。
8. 所有字典类型的数据页在自动化中通过七页列表动态发现，再逐个实际打开；覆盖数量与当前字典列表总数核对，结果保存到 reports/dictionary_coverage.json。
9. 顶部消息铃铛的查看全部进入 /user/notify-message（侧栏外入口）；开课计划消息详情跳转待办。另已点击系统欢迎消息和通知公告的历史详情入口，未发现额外路由。用户菜单仅有退出系统。相关实际 UI 记录见 reports/header_audit.json。
10. 补查确认学期有全年、Term 1、Term 2、Summer；选择可编辑 Term 2 后，新增课程表单可打开，六个表单标签均已逐一点击：课程基本信息、教学安排、教学模式与课时、在线课程大纲、招生要求与名额、其他。历史导入窗口和全年课程版本历史也已打开；未保存课程或上传文件。证据见 reports/course_form_audit.json。

新增课程的六个表单视图涵盖 Course Level/Belongs/Code/Title/Units、Co-listing/New Course/TA-only、教师和TA及多教师扩展、课时/频率/教室/多教学安排、CO录入及审批人员、先修/同修/互斥课程、Quota和班数、计算开关/Cost Pattern多段/配套资源需求。写入和条件分支的预期见开课相关用例，默认回归使用当前审批中学期的只读列表。


## 测试定位策略

正文使用实际 section 结构；侧栏按父菜单与叶子菜单限定；标签检查 aria-selected；折叠面板通过 aria-controls 关联；动态 Element Plus ID 不硬编码。输入按 placeholder 或表单标签定位，弹窗按可见 dialog 限定。列表等待数据变化，禁止固定延时替代同步。

# UI 测试用例

版本：2026-10-12。已实现用例对应根目录 pytest 脚本；测试结果见独立报告。文档中将同类参数组合集中说明，pytest 会逐参数独立执行。

默认前置：UAT 可访问；测试账号有对应菜单权限；现有基础数据不被其他测试同时修改。写入场景未在调研中提交，执行前必须明确可清理数据和角色范围。
